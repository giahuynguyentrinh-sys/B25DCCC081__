# Bài tập Lập trình hướng đối tượng – Quản lý học phí

- **Họ tên:** Nguyen Trinh Gia Huy
- **Mã sinh viên:** B25DCCC081
- **Lớp:** D25CQCC03-B

## Cấu trúc project

- `cau1/Main.java`: Chuẩn hóa thông tin sinh viên
- `cau2/Main.java`: Tính học phí theo hệ đào tạo
- `cau3/Main.java`: Quản lý danh sách học phí
- `cau4/Main.java`: Miễn giảm học phí và thống kê theo hệ

Mỗi câu là một file `Main.java` độc lập, đọc dữ liệu từ bàn phím (System.in).

## Hướng dẫn chạy

Yêu cầu: đã cài JDK 8 trở lên.

Ví dụ chạy câu 2:

    cd cau2
    javac Main.java
    java Main

Sau đó nhập dữ liệu từ bàn phím, hoặc đưa dữ liệu từ file vào:

    java Main < input.txt

Muốn chạy câu khác thì đổi `cau2` thành `cau1`, `cau3` hoặc `cau4`.
